## ✨ Features

### ESP
- Telemetry Overlay — real-time speed, gear, and lap times
- Track Map — visual track layout with car positions
- Race Info Panel — standings and gaps at a glance
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### Wallhack
- Setup Catalog — browse and organize car setups
- Livery Manager — manage custom livery notes
- HUD Customization — adjust overlay elements and colors

### Aimbot
- Practice Mode Notes — segment study on any track
- Ghost Car — compare your line with a reference lap
- Input Overlay — visualize steering and pedal inputs
